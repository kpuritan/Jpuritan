<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：愛のための自由の制限
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、ヤコボは福音の本質と共同体の交わりを見事に調和させた歴史的な判決を下しました。「異邦人の中から神に立ち返る人々を苦しめてはならない（割礼や律法順守を救いの条件として課してはならない）。」<br><br>その上でヤコボは、異邦人信徒に対し、偶像に汚れた物、不品行、絞殺された物、血を避けることを勧めました。これは救いの条件ではなく、長年モーセの律法に親しんできたユダヤ人信徒との「愛の交わりと一致」を守るための自発的な配慮でした。本日は、キリストにある真の自由と、隣人のための愛の自己制限を学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：愛のための自由の制限の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：福音の自由の防衛――「神に立ち返る者を苦しめるな」（19節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  ヤコボは異邦人に割礼や儀式律法を押し付けて苦しめることを断固禁じました。福音は人に重荷を負わせるのではなく、自由を与えるものです。救いの条件に人間の行いを付け加えてはなりません。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：道徳的純潔の保持と愛のための配慮（20節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  不品行の禁止は道徳律として当然の要求であり、偶像の肉や血の回避は、ユダヤ人兄弟たちのつまずきを防ぐための愛の配慮でした。真の自由とは「何でも自分勝手にしてよい」ことではなく、「愛のために権利を喜んで制限する」ことです。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：各地の会堂の現実と教会の平和と一致のための知恵（21節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  町々で律法が朗読されている現実の中で、教会が不必要な摩擦を避け、ユダヤ人と異邦人が一つの食卓で交わるための現実的で賢明な配慮がなされました。霊的指導者には真理の固守と愛の配慮の双方が求められます。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [キリストが与えてくださった福音の自由を喜び、律法主義の重荷から解放されること]：</strong> 人間の基準や規則で他者を裁くことをやめ、主の恵みの広大さを味わいましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [世の不品行や偶像崇拝の汚れから身を聖別し、清い生活を送ること]：</strong> 神の聖なる宮として、霊的・道徳的な純潔をしっかりと守り抜きましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [兄弟姉妹をつまずかせないために、自分の権利や自由を愛をもって自制すること]：</strong> 自分の自由を主張するよりも、共同体の一致と他者の徳を高めることを常に優先しましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、福音は私たちを完全な自由へと解放しました。その自由を肉の機会とするのではなく、隣人を愛し仕えるために用いるとき、教会には麗しい平和と一致が花開きます。愛による自由の歩みを全うしてまいりましょう。
</p>
