<p style="margin-bottom: 8px; line-height: 1.85;"><strong style="color: #0A1C36; margin-right: 6px; font-feature-settings: 'tnum';">[30]</strong> 彼らはそれを実行し、バルナバとサウロの手によって長老たちに送った。</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：恵みの証拠と愛の救援
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、アンテオケ教会が神の御言葉によって堅く建て上げられていた時、エルサレムからアガボをはじめとする預言者たちがやって来ました。アガボは聖霊によって、全世界に大飢饉が臨むことを予告しました。<br><br>この知らせを聞いたアンテオケ教会の弟子たちは、自分たち自身も困難に直面する状況の中で、ユダヤに住む母教会の兄弟たちを助けるために自発的に救援の品を送ることを決議しました。真の信仰は必ず愛の実を結びます。本日は、恵みを受けた魂が示す自発的な愛の分かち合いと、共同体の真の連帯について学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：恵みの証拠と愛の救援の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：聖霊の預言と歴史を統治される神の摂理（27-28節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  聖霊はアガボを通して大飢饉を前もって知らせ、教会に愛の備えをさせられました。歴史のすべての出来事、飢饉や社会の危機さえも神の主権の御手の中にあり、神はご自身の教会を守り育てるためにそれを用いられます。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：おのおのの力に応じた自発的で具体的な愛の実践（29節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  アンテオケの弟子たちは、誰かに強制されたからではなく、「おのおの自分の力に応じて」喜んで救援の献金を捧げました。福音によって心が変えられた信徒は、他者の必要を自分のこととして受け止め、具体的な犠牲と愛を惜しみません。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：バルナバとサウロによる誠実な救援の執行と教会の麗しい連帯（30節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  アンテオケ教会は集めた献金を信頼のおけるバルナバとサウロに託し、エルサレム教会の長老たちに届けさせました。異邦人教会がユダヤ人母教会を物心両面で支えることによって、キリストにあって民族の壁を越えた霊的・物質的な一致が美しく実現しました。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に、[困難な時代にあっても、神の主権的摂理を信頼して恐れないこと]：</strong> 世の中が不況や危機に揺れても、教会を養い導かれる主の御手に依り頼みましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に、[自分の力に応じて、困窮している兄弟姉妹に自発的な愛の手を差し伸べること]：</strong> 計算や見返りを求めず、主から受けた豊かな恵みを他者と分かち合う寛大な心を持ちましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に、[教会の交わりの中で誠実と信頼を保ち、主の体なる共同体の一致に仕えること]：</strong> 託された奉仕や献金を誠実に管理し、互いに支え合ってキリストの栄光を現しましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、真の恵みの証拠は、自分を越えて他者を愛し仕える行動となって現れます。アンテオケ教会のように、主の愛に動かされて互いに重荷を担い合い、神の国の温かい連帯を世に示してまいりましょう。
</p>
