<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：神の慰めに対する応答
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、死の淵から立ち上がったパウロは、翌日バルナバとともにデルベへと向かいました。デルベでの宣教は大いなる祝福を受け、多くの人々が主の弟子となりました。<br><br>その後、使徒たちは安全な近道を通って故郷アンテオケに帰ることもできたはずでした。しかし彼らは、自らを石打ちにし、追放した危険極まりないルステラ、イコニオム、ピシディアのアンテオケへとあえて引き返したのです。神から受けた大いなる慰めと命の回復に対するパウロの応答は、命をかけた弟子たちの養育でした。本日は、神の慰めを受けた者が示す愛と献身の歩みを学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：神の慰めに対する応答の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：デルベにおける豊かな福音の結実と弟子づくり（20-21節前半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  苦難の直後、デルベにおいてパウロたちは豊かな収穫を見ました。神は苦難の後に必ず慰めと実りを用意しておられます。福音の真の目的は、単なる改宗者ではなく「主の弟子」を育てることです。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：安全な道ではなく、迫害の危険地帯へと引き返す自己犠牲の愛（21節後半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  パウロとバルナバは自分たちの安全よりも、残された幼い信徒たちの信仰を心配しました。彼らは石打たれたルステラやイコニオムへあえて戻りました。羊のために命をかける真の牧会者の愛です。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：受けた慰めをもって他者を慰め強める霊的応答（21節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  パウロは自分が神から受けた超自然的な慰めと救出の力を、若い教会を励ますために惜しみなく注ぎました。神から受けた恵みは、他者を立て上げるための尊い資源となります。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [苦難の後に神が用意しておられる豊かな恵みと実りを期待すること]：</strong> 試練の時であっても落胆せず、神がその先に備えておられる祝福を信じて忠実に種を蒔きましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [自分の安全や快適さよりも、兄弟姉妹の信仰の成長と教会の確立を優先すること]：</strong> 自己中心的な保身を捨て、主の体なる教会の兄弟たちを愛し仕える献身を持ちましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [神から受けた慰めと恵みを独り占めせず、苦しむ隣人を励ますために用いること]：</strong> 自らが体験した主の真実を証しし、傷ついた人々を力づける励ましの人となりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、神の慰めを真に味わった者は、自分の安全の殻を破って危険な地へも愛をもって引き返します。主から注がれた愛と慰めに満たされ、教会の兄弟姉妹を力強く立て上げる真の弟子となってまいりましょう。
</p>
