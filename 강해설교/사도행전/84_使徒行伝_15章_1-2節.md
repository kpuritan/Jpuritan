<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：パウロが戦った理由――福音の純粋性の死守
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、使徒行伝第15章は、教会史における最大の転換点の一つである「エルサレム会議」を記録しています。アンテオケ教会にユダヤからある人々がやって来て、「割礼を受けなければ救われない」と教え始めたのです。<br><br>これは単なる儀式の問題ではなく、「キリストの十字架の恵みだけで十分なのか、それとも人間の律法の行いが救いに追加されねばならないのか」という福音の根幹に関わる致命的な危機でした。パウロとバルナバは沈黙せず、福音の純粋性を守るために命がけの激しい論争を展開しました。本日は、私たちが命をかけて守るべき「ただ恵みによる救い」の真理を学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：パウロが戦った理由――福音の純粋性の死守の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：福音を破壊する偽りの教え――「割礼と行いによる救い」の侵入（1節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  ユダヤ主義者たちは、信仰だけでなくモーセの律法や割礼を行わなければ救われないと主張しました。キリストの贖いに人間の行いを付け加えようとする教えは、十字架の恵みを無力化する「別の福音」です。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：福音の純粋性を死守するために妥協なく戦う使徒たちの勇気（2節前半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  パウロとバルナバは平和のために妥協する道を選ばず、真理のために激しく対決しました。教理の純粋性が脅かされるとき、真の指導者は沈黙せず、命をかけて真理の防波堤とならなければなりません。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：個人の争いに終わらせず、教会全体の公会議へと導く賢明な手続き（2節後半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  アンテオケ教会はこの問題を感情的な対立で終わらせず、使徒や長老たちが集まるエルサレムへ代表を派遣しました。教会の問題は、聖書の真理と聖霊の一致に基づいた公の秩序によって解決されるべきです。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [「ただ信仰のみ、ただ恵みのみ」による救いの真理を堅く握りしめること]：</strong> 自分の行いや功績を救いの条件とするあらゆる律法主義的な思いを退け、キリストの十字架のみを誇りましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [福音の真理が曲げられそうになるとき、恐れずに真理の側に立つ勇気を持つこと]：</strong> 人間関係の摩擦を恐れて信仰の妥協をせず、聖書の御言葉にしっかりと根ざして立ちましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [教会内の課題や教理の混乱を、祈りと御言葉の公の秩序によって解決すること]：</strong> 個人的な感情論を排し、キリストの体なる教会の健全な一致と指導に従いましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、パウロが命がけで戦って守り抜いたのは、「キリストの恵みによる完全な救い」でした。いかなる人間の行いも加えることのできないキリストの十字架の純粋な福音を固く守り、後世へと継承してまいりましょう。
</p>
