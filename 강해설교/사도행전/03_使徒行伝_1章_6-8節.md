<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：神の国の進展と「すでに、しかし未だ」の時代
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、使徒行伝第1章は、ルカによる福音書を総括しながら、復活された主イエスが天に昇られるまでの40日間の御業を鮮やかに要約しています。第3節にあるように、主イエスが復活後の40日間において弟子たちに最も重点を置いて教えられた主題は、他でもなく<b>「神の国（御国）のこと」</b>でした。

その教えを聞いていた使徒たちは、昇天を目前にした主イエスに切実な問いを投げかけました。「主よ、イスラエルの国を回復してくださるのは、今この時なのですか」（6節）。彼らの関心は、復活の栄光を現されたキリストが、今や圧倒的な権威をもってローマ帝国を打ち倒し、神政政治による地上のイスラエル王国を再建してくださるのかという点にありました。しかし、主イエスは彼らの世俗的で狭い期待を正し、天の御座へと昇られる直前、神の国に関する最も決定的で核心的な御言葉を告げられたのです（7～8節）。

20世紀の多くの神学者たちが深く探求したように、聖書が啓示する神の国の本質は<b>「すでに（Already）、しかし未だ（Not Yet）」</b>という救済史的緊張関係の中にあります。
これを説明する際、第二次世界大戦の決定的な歴史がよく例えられます。1944年6月6日のノルマンディー上陸作戦は「決定の日（D-Day：Decision Day）」と呼ばれ、連合軍の最終的な勝利が決定づけられた日でした。しかし、ナチス・ドイツが完全に降伏し、戦争が最終結着を迎えたのは翌1945年の「勝利の日（V-Day：Victory Day）」でした。D-DayとV-Dayの間の期間、戦いは依然として激しく続きましたが、勝利の結末はすでに確定していたのです。

主イエスが初臨され、十字架で死に打ち勝って復活された出来事こそが、全宇宙の救済史における「D-Day」です。神の国はすでに始まりました。そして、主が栄光のうちに再臨される日こそが最終的な「V-Day」です。現在を生きる私と皆様は、このD-DayとV-Dayの狭間にある<b>「神の国の前進（Advancing the Kingdom）の時代」</b>、すなわち恵みによる「救いの最後の時（終わりの時代）」を生きています。本文を通して、主が弟子たちに示された神の国の真の姿と、私たちが担うべき聖なる使命について学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：神の国の進展と「すでに、しかし未だ」の時代の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：世俗的・政治的な誤解を捨て、霊的な「終わりの時代（救いの時）」を直視すること（6節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  第6節において、弟子たちが「イスラエルの回復は今ですか」と問うた背景には、旧約の預言に対する彼らなりの知識がありました。イザヤ書第2章1～3節には、「終わりの日に、主の家の山（シオンの山）はすべての山の上に堅く立ち、万国の民がそこへ集まって来て、主の道を学ぶであろう。律法はシオンから、主の御言葉はエルサレムから出る」と約束されています。
イエス様がエルサレムを強調されたため、弟子たちはこのイザヤの預言が、ローマ政権からの政治的解放とダビデ王朝の復興という地上的な形で今すぐ成就するのではないかと焦りを抱いて期待したのです。

しかし、弟子たちの霊的理解力はまだ不十分であり、神の国の霊的な広がりを理解できていませんでした。シオンの山とエルサレムから世界へと広がる神の国とは、目に見える世俗の国家体制ではなく、<b>キリストの福音と聖霊の統治が全世界の諸民族に及ぶ霊的実在</b>であり、その最終的な成就は主の「再臨の時」に訪れるものだったのです。
主イエスは弟子たちの未熟さを感情的に叱責されませんでした。聖霊が五旬節に降臨されれば、彼らの霊の目が開かれ、神の救済計画の壮大な全貌を悟るようになることをご存知だったからです。

使徒行伝第2章17節において、聖霊を受けたペテロはヨエル書の預言を解き明かし、「神は言われる、終わりの日に、わたしの霊をすべての肉なる者に注ぐ」と宣言しました。聖霊が降臨されたその日こそが「終わりの時（末世）」の開幕でした。この「終わりの時代」とは、<b>審判が下る前にあらゆる民族から神の民が救い出される「恵みと救いの最後の期間」</b>です。現代の多くの人々がこの切迫した救いの時を知らずに世の繁栄だけに溺れて生きていますが、聖徒は神の救済史の時計をはっきりと見つめ、日々を厳粛な信仰をもって生きなければなりません。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：時と時期、世の裁きは聖父なる神の絶対的主権に完全に委ねること（7節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  第7節で、主イエスは断固として答えられました。<b>「時や時期は、父がご自身の権威によってお定めになったのであって、あなたがたの知るところではない。」</b>
神の国の最終的な完成の時、そして世の邪悪な政権に対する裁きの時は、被造物である人間の詮索や計算の領域ではなく、父なる神の絶対的主権に属する聖なる領域です。私たちが救われ、新生を経験して生命の書に名が記される恵みも、究極的には父なる神の主権的な選びと御心に基づいています。

聖書全体を見れば、神は歴史の背後で常に世の政権と諸民族の罪を見極めておられます。イザヤ書やダニエル書に預言されたように、バビロン、ペルシャ、ギリシャ、ローマといった強大な帝国も、神の測り（主権の杖）によってその罪が量られ、神の時にことごとく裁かれて崩壊していきました。
創世記第15章16節において、神はアブラハムに「あなたの子孫は四代目の時にこの地に帰って来る。アモリ人の罪がまだ満ちていないからである」と仰せられました。神は恣意的に裁かれるのではなく、罪が満ちるのを忍耐深く見守り、完全な公義に基づいて正確な時に裁きを執行されるのです。

16世紀のイギリスにおいて、血のメアリー女王による激しいカトリック反動と迫害の中で数百人もの忠実な牧師や聖徒たちが殉教の血を流したように、歴史の中で神の民はしばしば邪悪な世俗権力によって激しい試練に遭遇します。
しかし聖徒は、「神よ、なぜ悪人を放置されるのか」と絶望したり、人間の血肉の力で復讐しようとしてはなりません。悪に対する最終的な審判は、キリストの再臨の時に父なる神が公義をもって完全に成し遂げられます。だからこそ主は「あなたがたが気を煩わせる必要はない。父の主権に信頼して委ねよ」と命じられたのです。私たちは歴史の統治者であられる神を信じ、今日の持ち場において忠実に生きることが求められています。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：聖霊の権能を受け、地の果てまでキリストの証人となって御国を前進させること（8節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  時と時期を神の手に委ねた弟子たちに対し、主イエスが下された唯一かつ絶対的な使命が第8節に示されています。<b>「しかし、聖霊があなたがたの上に臨むとき、あなたがたは力を受けます。そして、エルサレム、ユダヤとサマリアの全土、さらに地の果てまで、わたしの証人となります。」</b>
これこそが、教会がこの地上に存在する究極の目的であり、私たちが全精力を注ぐべき唯一の関心事です。

「証人（マルテュス：martys、殉教者の語源）」とは、聖霊の超自然的な力を受けて、キリストの十字架の贖いと復活の事実を命がけで証言する者たちです。この福音の進展は、エルサレムから始まり、ユダヤ、サマリアという民族的・宗教的障壁を越え、当時の世界の果て（パウロにとってはローマ、さらにはイスパニア／スペインに至るまで）へと力強く広がっていきました。
使徒行伝第28章30～31節において、囚われの身となったパウロがローマの牢獄にあっても、訪れるすべての人に「神の国を宣べ伝え、主イエス・キリストに関するすべてのことを大胆に教え続けた」ように、神の国は人間のいかなる束縛をも打ち破って前進（Advancing）し続けています。

主の祈りにある「御国が来ますように（マタイ6:10）」という祈りは、全世界のあらゆる民族の中から神の民が立ち上がり、キリストの王権に心から服従する群れが起こされることを意味します。
私たちが日々営む仕事、事業、家庭生活、学業のすべての活動は、単なる生計の手段ではなく、この「神の国の前進とキリストの証人となること」に究極の焦点が置かれなければなりません。「まず神の国と神の義を求めなさい。そうすれば、これらのものはすべて添えて与えられます（マタイ6:33）」。私たちが神の国に全生涯を捧げるとき、天の御座におられる教会の頭キリストが、私たちの人生のすべてを顧み、豊かに養い、勝利へと導いてくださるのです。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に、[救いの「終わりの時代」を覚える霊的緊張感の回復]：</strong> 現代社会の安逸や世俗の波に流されることなく、今はすべての魂に福音が宣べ伝えられるべき「恵みの最後の時」であることを自覚しましょう。自分自身と家族、隣人の救いのために祈り、目覚めた信仰生活を送りましょう。世の終わりに主の御前に立つ準備を整えましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に、[世の不条理と未来の時を神の主権に委ねる平安]：</strong> 世の政治情勢の混乱や個人的な試練に直面しても、動揺したり人間の知恵で思い煩うのをやめましょう。万物を正しく裁かれる父なる神の公義とタイムテーブルにすべてを委ね、心の平安を保ちましょう。神の主権を信じる者には恐れがありません。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に、[生活の全領域を「キリストの証人」として生きる献身]：</strong> 職場、家庭、地域社会における日々の歩みを、キリストの証人としての尊い舞台として受け止めましょう。聖霊の満たしを求め、言葉と愛の行いをもって福音を証しし、神の国の前進に用いられる器となってください。私たちの全存在を神の国の栄光のためにささげましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、主イエス・キリストは十字架と復活によって救いの勝利を確定され（D-Day）、今や天の御座から聖霊の権能をもってご自身の教会を用い、御国を完成の栄光（V-Day）へと力強く前進させておられます。

時と時期に対する無益な推測や世俗的な心配にエネルギーを奪われることなく、聖霊の力に満たされて地の果てまでキリストの証人として立ち上がりましょう。神の国の完成のその日、主の右の座に立ち、忠実なしもべとして永遠の称賛と栄光に預かる聖徒の皆様となりますよう、主イエス・キリストの御名によって祝福いたします。
</p>
