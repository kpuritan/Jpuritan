<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：真夜中の非凡な祈りと賛美
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、むち打たれた傷口が激痛を放ち、足枷に縛られた冷たい地下牢の真夜中――人間的に見れば絶望と怨嗟の声が漏れるはずの場所から、信じがたい歌声が響き渡りました。パウロとシラスは神に向かって熱心に祈り、声を張り上げて神を賛美していたのです。<br><br>他の囚人たちは息をのんでこの聖なる賛美に聞き入っていました。その瞬間、天地を揺るがす大地震が起こり、牢獄の土台が揺れ、すべての鉄の扉が開き、すべての鎖が外れました。苦難の真夜中にささげられる祈りと賛美こそ、地獄の門を打ち破る最強の力です。本日は、真夜中の非凡な賛美と、神の全能の介入を学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：真夜中の非凡な祈りと賛美の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：苦痛と暗闇を突き破る「真夜中の祈りと賛美」（25節前半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  使徒たちは環境や肉体の痛みに支配されませんでした。彼らは神の主権と善意を確信し、夜の静寂の中で祈り、賛美の歌を歌いました。真の賛美は、快適な環境からではなく、神への無条件の信頼から湧き上がります。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：囚人たちを圧倒した賛美の証し力（25節後半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  「囚人たちも聞き入っていた。」 絶望の牢獄で響く聖徒の賛美は、周囲の傷ついた魂たちに強烈な霊的衝撃と慰めを与えました。聖徒の苦難中の賛美は、世に対する最高の説教です。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：大地震による神の直接的介入とすべての鎖の脱落（26節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  神は賛美の中に臨在されます。大地震が牢の土台を揺さぶり、すべての扉が開き、全員の足枷が外れました。神はご自身の民を縛るあらゆるサタンの鎖を一瞬にして打ち砕かれます。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [人生の最も暗い「真夜中」にこそ、不平を捨てて神への祈りと賛美をささげること]：</strong> 苦しみや痛みの時こそ、神の恵みと十字架を見上げて感謝と賛美の歌を口ずさみましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [どのような苦難の場にあっても、周囲の人々にキリストの平安を証しする存在となること]：</strong> 絶望的な状況でも取り乱さず、主の平安を宿すことで周囲の人々に福音の光を輝かせましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [神がすべての束縛の扉を開き、鎖を断ち切ってくださる全能の救いを信じること]：</strong> 罪や恐れ、絶望の足枷を主が解き放ってくださることを確信して、大胆に信仰の祈りをささげましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、真夜中の牢獄でささげられた祈りと賛美は、牢の土台を揺るがし鎖を外しました。人生の暗闇に直面するとき、全能の神を賛美し、すべての鎖を断ち切る神の勝利を体験してまいりましょう。
</p>
