<p style="margin-bottom: 8px; line-height: 1.85;"><strong style="color: #0A1C36; margin-right: 6px; font-feature-settings: 'tnum';">[34]</strong> それから二人を自分の家に案内して食事をもてなし、神を信じるようになったことを家族全員で心から喜んだ。</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：知・情・意の全人的変化
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、福音の御言葉を聞いて主イエスを信じた看守とその家族には、その夜のうちに劇的な全人的変化が現れました。かつて使徒たちを奥の牢獄に閉じ込め足枷をはめた無慈悲な看守が、使徒たちを引き取って自らの手で血まみれの打ち傷を丁寧に洗い清めたのです。<br><br>そして家族全員が直ちにバプテスマを受け、使徒たちを自宅に招いて心尽くしの食事をもてなし、神を信じるようになった喜びに家中が包まれました。真の回心は、知性の理解（知）、感情の喜びと愛（情）、意志的な行動と服従（意）のすべてを根底から変革します。本日は、救われた魂に現れる知・情・意の美しい全人的変化を学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：知・情・意の全人的変化の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：冷酷な看守が愛の奉仕者へと変貌した意志的・行動的変化（33節前半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  看守は自らの手で使徒たちの傷を洗いました。福音の光に打たれた罪人は、利己心と冷酷さを脱ぎ捨て、隣人の痛みを癒やす具体的な愛の実践者へと変えられます。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：真理を受け入れた知性的決断と即座のバプテスマ（33節後半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  彼らは夜中であるにもかかわらず、遅延することなくバプテスマを受けました。福音の真理を正しく理解した知性は、直ちに聖書の命令に従順に従う信仰の決断を下します。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：家庭を満たした聖なる歓喜と愛のおもてなし（34節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  食事の接待とともに、家中が「神を信じるようになった大いなる喜び」に満たされました。救いは家庭に暗闇を追い払い、天の平和と聖霊の喜びをもたらします。これこそが全人的回心の実像です。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [キリストを信じる信仰が、具体的な隣人愛と奉仕の行動となって現れること]：</strong> 言葉だけの信仰にとどまらず、傷ついた人の痛みを洗い癒やす実践的な愛を生きましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [福音の真理に従い、遅延することなく従順の生活を送ること]：</strong> 御言葉が示されたなら、ためらうことなく直ちに主の命令に従いましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [神を信じるようになった救いの喜びを、家庭と教会の交わりの中で豊かに味わい証しすること]：</strong> 家庭の中にキリストの恵みを満たし、共に喜び感謝する信仰の家庭を築きましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、福音は人間の全存在を根本から新しく造り変えます。知・情・意のすべてをもって主を愛し、隣人に仕え、神を信じる大いなる喜びに満たされて歩んでまいりましょう。
</p>
