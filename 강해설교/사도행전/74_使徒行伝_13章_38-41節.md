<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：恵みに満ちた福音の宣言
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、使徒パウロの説教は、ついに福音の最も核心的な真理、すなわち「信仰による義認（称義）」の宣言へと到達します。「このイエスによって罪の赦しが宣べ伝えられ、モーセの律法では義と認められなかったすべてのことについて、信じる者はみな義と認められる。」<br><br>どれほど律法を行おうとしても自らを救うことができない罪人にとって、ただキリストを信じるだけで神の前に完全に義とされるという福音は、驚くべき恵みです。しかし同時にパウロは、この恵みを軽蔑し拒む者には恐ろしい神の審判が臨むことを厳粛に警告しました。本日は、恵みの福音の驚くべき豊かさとその責任を学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：恵みに満ちた福音の宣言の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：キリストの御名によって無償で与えられる完全な罪の赦し（38節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  パウロは「この方によって罪の赦しが宣べ伝えられている」と告げました。人間の努力や儀式ではなく、キリストの十字架の血潮によってのみ、過去・現在・未来のすべての罪が完全に洗い清められます。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：モーセの律法の限界と信仰による完全な義認の恵み（39節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  律法は罪を自覚させることはできても、人を義とすることはできません。しかしイエス・キリストを信じる者は誰でも、キリストの完全な義を着せられ、神の前で「罪なき義人」として受け入れられます。これこそが改革派信仰の真髄です。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：恵みをあざける者への厳粛な警告と信仰の決断（40-41節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  パウロは預言者ハバククの言葉を引用し、神の偉大な恵みの御業をあざけり信じない者に滅びが臨むことを警告しました。福音の招きを軽視することは、永遠の破滅を自ら選ぶことです。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [自分の行いや功績を頼みとせず、ただキリストを信じる信仰によって義とされる恵みに安息すること]：</strong> 自己義認の思いを捨て、キリストが成し遂げてくださった十字架の義だけを誇りましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [罪責感や恐れから解放され、神の愛された子どもとしての自由と平安を味わうこと]：</strong> キリストにあって完全に罪が赦された確信を握りしめ、感謝と喜びをもって日々を生きましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [福音の恵みを軽んじることなく、畏れ敬う心をもって主の御言葉に聞き従うこと]：</strong> 世の惑わしにあざけり同調せず、真理の福音を真剣に受け止め、周囲の人々にもこの救いを伝えましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、律法が成し得なかった救いを、神はイエス・キリストへの信仰によって完璧に成し遂げてくださいました。この恵みの福音を心から信じて義と認められた喜びをもって、神を愛し隣人を愛する幸いな歩みを続けてまいりましょう。
</p>
