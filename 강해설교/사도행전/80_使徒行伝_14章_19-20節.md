<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：苦難の中で悟る真理
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、神として拝まれそうになった直後、世の評価は一瞬にして反転しました。遠くアンテオケやイコニオムから追ってきた敵対者たちが群衆を扇動し、パウロは激しい石打ちに遭い、死んだと思われて町の外に投げ捨てられたのです。<br><br>かつて神と呼んだ群衆が今や石を投げる――世の称賛がいかに移ろいやすいかを痛感させられます。しかし、悲嘆に暮れる弟子たちが取り囲んで祈っていると、パウロは死の淵から奇跡的に立ち上がり、再びその町へと堂々と入っていきました。本日は、極限の苦難の中で悟る神の国の真理と、死をも恐れない不屈の信仰を学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：苦難の中で悟る真理の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：世の称賛の儚さと、執拗なサタンの攻撃（19節前半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  昨日まで神として拝もうとしていた人々が、扇動されるや否やパウロを石打ちにしました。世の称賛や人気は朝露のように儚いものです。私たちは人の評価に一喜一憂してはなりません。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：石打ちと町の外への投棄――死の淵における殉教の体験（19節後半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  パウロは無数の石を浴びて血まみれとなり、息絶えたと見なされて捨てられました。福音宣教には命をかける苦難が伴います。しかしパウロはこの苦難を通して、キリストの十字架の苦しみに深くあずかる特権を味わいました。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：弟子たちの祈りと、死の淵からの奇跡の立ち上がり（20節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  弟子たちが取り囲む中で、神の超自然的な力がパウロに臨み、彼は立ち上がりました。そして恐れて逃げるのではなく、自分を石打ちにした町へと再び歩み入りました。キリストの復活の命に生きる者は、いかなる死の脅威にも屈しません。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [世の人々の気まぐれな評価や称賛に心を奪われないこと]：</strong> 人の称賛を求めず、ただ神の御前に義と認められることを最高の願いとしましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [信仰のゆえに受ける苦難や痛みを、神の深い恵みを知る機会として受け止めること]：</strong> 試練の時こそキリストの苦難に与り、霊的に研ぎ澄まされる時であることを覚えましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [困難に倒れても、聖霊の力と兄弟姉妹の祈りによって再び立ち上がること]：</strong> どのような絶望の淵にあっても諦めず、主が与えてくださる復活のいのちによって前進しましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、世の石打ちはパウロを殺すことができませんでした。キリストにある者は倒れても再び立ち上がります。苦難を恐れず、復活の力に満たされて使命の道を力強く歩み続けてまいりましょう。
</p>
