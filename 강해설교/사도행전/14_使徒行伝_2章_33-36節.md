### 1. 序論：三位一体の神の御業とキリストの天の即位

使徒行伝第2章33節から36節は、ペテロによる五旬節（ペンテコステ）説教の神学的頂点であり、キリスト論・聖霊論の核心が凝縮された極めて重要な御言葉です。

この短い四つの節の中に、**聖父なる神、御子イエス・キリスト、聖霊なる神**という三位一体の各位の御名と御業が克明に記されています。
- **聖父なる神：**御右の手をもって御子を高く上げ、約束の聖霊を与え、敵を足台とされる方。
- **御子イエス・キリスト：**十字架で死なれ、復活して天の御座の右に着座し、主でありキリストとして即位された王。
- **聖霊なる神：**御父から御子に与えられ、御子によって地上の教会と信徒たちに力強く注ぎ出された助け主。

聖書は人間中心の偉人伝ではありません。聖書の中心は常に三位一体の神ご自身であり、神がなされた偉大な救済の御業です。

ペテロはここで、ユダヤ人たちが十字架につけて殺したナザレのイエスを、父なる神が復活させ、天の御座の右に着座させて**「全宇宙の主、永遠の王（キリスト）」**として即位させられたことを力強く宣言しています。そして、弟子たちに臨んだペンテコステの驚異的な出来事は、まさに即位された王イエスが天から聖霊を注ぎ出してくださった結果であると解き明かします。

本日は、天の御座に着座された生けるキリストが、今私たちをどのように統治し、聖霊を通してどのような恵みを注いでおられるのかを深く学んでまいりましょう。

### 2. 本論：天の御座に即位されたキリストの三重の統治

```
【天の御座に即位されたキリストの御業】
┌─────────────────────────────────────────────────────────┐
│ 1. 聖霊の注ぎと霊的再生（33節） ── もう一人の助け主による統治 │
│    ・ヨハネ 14:16, 26, 16:8-13 / 罪の自覚・真理の導き・将来の希望 │
├─────────────────────────────────────────────────────────┤
│ 2. 詩篇 110:1の成就と王権（34-35節前半） ── 全宇宙と教会の統治 │
│    ・マタイ 28:18, エペソ 1:20-23 / 生ける大祭司・王への畏敬と服従 │
├─────────────────────────────────────────────────────────┤
│ 3. 敵の完全な征服と救いの完成（35節後半-36節） ── 御国の完成 │
│    ・Ⅰコリント 15:23-26 / 選びの民（定数）の救出と父への奉献 │
└─────────────────────────────────────────────────────────┘
```

#### 第1の要点：約束された聖霊を注がれる「生ける主の恵み」（33節）

ペテロは33節でこう語ります。**「神の右の座に上げられたイエスは、約束された聖霊を父から受けて、あなたがたがいま見聞きしているこの聖霊を注いでくださったのです。」**

主イエスが天の御座に着座されて最初になされた御業は、**「聖霊を教会に注ぎ出すこと」**でした。
イエス様は地上におられた公生涯の間、弟子たちに聖霊の到来を繰り返し約束されました（ヨハネ 14, 15, 16章）。

1. **もう一人の助け主（ヨハネ 14:16, 26）：**
   「わたしが父にお願いすると、父はもう一人の助け主をあなたがたに与えて、永遠にあなたがたと共におらせてくださる。」
   イエス様が天の御座で執り成してくださる助け主であると同時に、聖霊は私たちの心の内にとどまり、主の御言葉をすべて教え、思い起こさせてくださる地上の助け主です。
2. **罪と義と裁きを悟らせる働き（ヨハネ 16:8-11）：**
   聖霊は、私たちが祈りの中で自らの罪の恐ろしさを悟り、悔い改めて罪を離れ、キリストの十字架の義にすがるよう導かれます。
3. **すべての真理と将来への導き（ヨハネ 16:13）：**
   「真理の御霊が来ると、あなたがたをすべての真理に導いてくださる……また、やがて起ころうとする事をも知らせてくださる。」
   聖霊は、信徒（特に青年たち）の人生に対する神の尊い召命と御計画を心に示し、確信をもって生きる力を与えてくださいます。

キリストが天に昇られ、聖霊を送ってくださったからこそ、私たちの信仰生活は乾いた形式ではなく、生きた感動、熱い愛、深い感謝に満たされるのです。

---

#### 第2の要点：万物を統治し、教会を守られる「王としての即位」（34-35節前半）

ペテロは続けて、詩篇110篇1節というメシア預言の最高峰を引用します。
**「ダビデは天に上りませんでしたが、自らこう言っています。『主は、私の主に仰せになった。「わたしの右の座に着きなさい。わたしが、あなたの敵をあなたの足台とする時まで。」』」（34-35節）**

- **ダビデが見たキリストの即位：**
  ダビデ自身は天に昇っていませんが、預言者として聖霊の照らしを受け、自分の子孫として来られるメシアが神の右の御座に着座される栄光をあらかじめ見ていました。
- **「神の右の座」の霊的意味（マタイ 28:18, エペソ 1:20-23）：**
  「天と地におけるすべての権威が、わたしに与えられました。」
  神の右の座に着くとは、父なる神のすべての支配権、権勢、力、主権を委ねられ、**「万物の頭、王の王」**として即位されたことを意味します。この世のいかなる大統領や皇帝の権力も、主イエスの至高の主権の前には微塵にすぎません。
- **生ける王への畏敬と服従（詩篇 50篇, Ⅱコリント 7:1）：**
  主イエスは今、十字架の上に死んだままおられるのではありません（カトリックのミサの誤謬）。主は天の御座で生きて教会を治めておられます。口先だけで「主よ、主よ」と呼びながら戒めを破り、世俗にまみれて生きる者は、王であられる主を侮る者です。私たちは王であられるキリストの主権を恐れ敬い、その御声に従順に従わなければなりません。

---

#### 第3の要点：すべての敵を滅ぼし、御国を完成される「終末の勝利」（35節後半-36節）

最後にペテロは、キリストの統治がいつまで続き、どのように完成するのかを告げます。
**「わたしが、あなたの敵をあなたの足台とする時まで。ですから、イスラエルの全家は、このことを確信をもって知らなければなりません。神が、あなたがたが十字架につけたこのイエスを、主ともキリストともされたのです。」（35-36節）**

1. **すべての敵の征服（Ⅰコリント 15:23-26）：**
   キリストは、サタンのすべての支配と権勢を打ち砕き、最後に滅ぼされる敵である「死」をも完全に克服されるまで、王として統治し続けられます。
2. **選びの民の完成と御国の奉献（ヨハネ 10:16, 黙示録 7:4-9）：**
   キリストの統治の最大の目的は、父なる神があらかじめ選ばれた民（象徴数としての14万4千人、救いの総数）を一人残らず救い出し、完成された神の国を父なる神に捧げることです。
3. **教会の世界的使命：**
   主が再び来られるその日まで、教会は王の命令に従い、全地に福音を宣べ伝え、開拓教会を支援し、真理の書物を出版して魂を救い出す使命に全力を尽くさなければなりません。

### 3. 適用：王であられる生けるキリストに仕える3つの実践

私たちは、天の御座で統治しておられる主イエス・キリストを仰ぎ見つつ、どのように生きるべきでしょうか。

```
【生ける王キリストに仕える信仰の実践】
1. 聖霊の満たしと真理の歩み ── 日々の祈りの中で罪を捨て、聖霊の導きに従う
2. 王の主権への絶対的服従 ── 形式的な信仰を捨て、神を畏れる敬虔な生活を送る
3. 御国の完成を目指す宣教の献身 ── 福音宣教と教会の建て上げのために忠実に仕える
```

#### ① 聖霊の豊かな油注ぎを求め、霊的感動をもって生きる
イエス様が天から注いでくださった聖霊を日々祈り求めましょう。
祈りの中で罪を照らし出されたなら直ちに悔い改め、真理の御霊が教えてくださる人生の希望と計画に従って、情熱をもって前進してください。

#### ② キリストを人生の真の王としてお迎えし、恐れ敬って従う
主イエスは今、天の御座で私たちの全生涯を見守っておられます。
世の偶像や肉の欲望に妥協せず、パウロのように「神を恐れつつ聖潔を全うする」敬虔な歩みを保ちましょう。

#### ③ 主の再臨と御国の完成を待ち望み、福音伝道に励む
キリストがすべての敵を踏み台とされるその日まで、神の選びの民を集める務めが私たちに託されています。
身近な家族や友人への伝道、教会の宣教の働きのために、時間と祈りと物質を惜しみなく捧げましょう。

### 4. 結論：十字架につけられたイエスが、主でありキリストである

使徒行伝2章33節から36節において、ペテロが叫んだ結論は明確です。
**「あなたがたが十字架につけたこのイエスを、神は主ともキリストともされた。」**

人間は主イエスを嘲り、十字架につけて葬り去ろうとしましたが、神は彼を高く上げ、全宇宙の絶対君主として即位させられました。
この生ける王イエス・キリストが、今私たちに聖霊を注ぎ、私たちを守り、導いておられます。この栄光の王を心から賛美し、喜びと従順をもって仕えてまいりましょう。

---

### 5. 締めくくりの祈り

**全能にして主権者であられる父なる神様。**
十字架で死なれた主イエス・キリストを死者の中からよみがえらせ、天の御座の右に着座させて主とし、キリストとして即位させられた偉大な救済の御業を心より賛美いたします。

主よ、天の御座に着座された主イエスが、約束の聖霊を豊かに注ぎ出してくださり、私たちに罪の悔い改めと救いの恵み、そして永遠の命を与えてくださったことを感謝いたします。私たちの信仰が乾いた形式に陥ることなく、日々聖霊の豊かな恵みと感動に満たされる者とならせてください。

王であられるキリストの至高の主権を畏れ敬い、日々の生活において御言葉に忠実に従わせてください。そして、すべての敵を踏み台とし、救いの民が完成する主の再臨の日まで、福音を証しし教会を建て上げる尊い器として私たちをお用いください。

天の御座で今も生きて治められる、主イエス・キリストの尊き御名によって、感謝と祈りを御前に捧げます。

**アーメン。**
