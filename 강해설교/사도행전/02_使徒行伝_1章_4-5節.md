<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：肉的な恐れを制し、約束の聖霊を待つ信仰
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、使徒行伝第1章1節から8節は、復活された主イエス・キリストが天の御座へと昇天される直前、愛する使徒たちに遺された極めて重要で切実な御言葉の記録です。その中でも本日の本文である第4節と5節において、主イエスは弟子たちに一つの厳粛かつ絶対的な命令を下されました。それは、<b>「エルサレムを離れるな。わたしから聞いた、父の約束を待ちなさい」</b>という命令です。

当時の弟子たちの置かれていた現実的・心理的立場を深く想い巡らしてみてください。エルサレムとは一体どのような場所だったでしょうか。そこは、自分たちが心から愛し、命を捧げて仕えてきた主イエス・キリストを無残にも捕らえ、不法な裁判にかけ、呪いの十字架につけて処刑した血塗られた場所です。ユダヤの大祭司やサンヘドリンの宗教指導者たちの冷酷な暴虐、ローマ帝国の政治的権力による威嚇、激しい憎悪と敵意が渦巻く、弟子たちにとっては最大の恐怖とトラウマの地に他なりませんでした。弟子たちの肉的な感情や人間的な本能、自己保身の論理からすれば、一刻も早くこの恐ろしいエルサレムを脱出し、安全で心休まる緑豊かなガリラヤの故郷へ逃げ帰りたいと願うのが当然の心理でした。

しかし、主イエスは「エルサレムを去ってはならない」と固く厳命されました。なぜ主は、このような人間的な本能に逆らう厳しい命令を下されたのでしょうか。それは、弟子たちの肉的な判断や恐れの感情、自分勝手な逃避衝動を完全に抑え込ませるためでした。そして、<b>「これからの救済史において、あなたがたの肉体を支配し、神の御業を成し遂げられる真の主体はあなたがた自身ではなく、天から注がれる聖霊なる神である」</b>という決定的な霊的事実を骨の髄まで悟らせるためでした。

主は、人間的な熱心や血気、自己中心的な焦りで勝手に動き出すことを断固として禁じられ、天の父が旧約の昔から約束された聖霊が臨むまで、ひたすら祈りつつ待つようにと命じられたのです。神の贖いの歴史において、なぜ父なる神は聖霊を約束され、復活の主イエスは弟子たちに聖霊を待望するよう命じられたのでしょうか。本日の本文を通して、約束の聖霊が送られる三つの聖なる目的を深く考察し、現代を生きる私たちが肉的な恐れを制していかに聖霊を待ち望むべきかを学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：肉的な恐れを制し、約束の聖霊を待つ信仰の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：真理の御霊として救いの福音と教理を悟らせ、生きた信仰を生み出すため（4節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  第4節において、主イエスは「父の約束」を待てと命じられました。一部の誤った神学者たちが主張するように、旧約は「父の時代」、福音書は「子の時代」、使徒行伝以降は「聖霊の時代」と機械的に時代を区分してはなりません。父・子・聖霊の三位一体の神は、創世以前から永遠に同一の本質において共に働いておられます。すでに旧約聖書において、父なる神は御子メシアをお遣わしになる約束と共に、<b>「聖霊をお遣わしになる約束」</b>を絶え間なく与えておられました（創世記17章、申命記30:6、エゼキエル36:26-27）。

預言者イザヤもイザヤ書44章3～4節において、「渇いた者に水を注ぎ、乾いた地に小川を流し、わたしの霊（聖霊）をあなたの子孫に注ぐ」と力強く約束しました。では、なぜ神はキリストの預言だけでなく、聖霊の約束をも与えなければならなかったのでしょうか。その根本的な答えはイザヤ書53章1節にあります。<b>「私たちが伝えたことを誰が信じたか。主の御腕は誰に現れたか。」</b>

イザヤの時代の人々は、預言者がいくら受難のメシアの約束を語っても全く信じませんでした。なぜなら、アダムの堕落によって全人類の知性、感情、意志は完全に腐敗し、神に対して霊的に死んでいたからです。人間の肉の力や知恵では、神の深みである十字架の福音を悟ることも信じることも絶対にできません。主の御腕が現れ、罪人が自らの罪深さを悟り、キリストの十字架の贖いを人格的に受け入れるためには、絶対に<b>「聖霊なる神の主権的な照明と有効な召し」</b>が必要不可欠だったのです。

ヨハネによる福音書第14章16～17節において、主イエスは「もう一人の助け主（パラクレートス）、真理の御霊」を約束されました。使徒ヨハネがヨハネの手紙第一第2章20節、27節で「あなたがたは聖霊の油注ぎを受けており、すべてを知っている」と語ったように、聖霊こそが救いの教理を魂の奥底に生きた真理として悟らせてくださる方です。もし聖霊の内なる証印と悟りがなければ、聖書をいくら学んで文字通りの知識を蓄えていても、それは悪魔でさえ持っている「歴史的・知的な空虚な知識」にとどまり、魂を新生させる真の信仰には至りません。真理の御霊が臨まれるとき初めて、死んだ文字が生ける神の御声へと変えられ、キリストと霊的に固く結び合わされるのです。現代の教会においても、ただ聖霊の照らしによってのみ、魂が打ち砕かれ、生きた悔い改めと救いの確信へと導かれます。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：聖霊と火のバプテスマにより、罪の腐敗性を焼き尽くし霊魂を完全に清めるため（5節前半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  第5節において、イエス様は洗礼者ヨハネの言葉を直接引用されます。「ヨハネは水でバプテスマを授けたが、あなたがたはまもなく聖霊によるバプテスマを受ける」。この御言葉の背景には、ルカによる福音書第3章16節におけるヨハネの預言があります。「その方は、聖霊と火をもってあなたがたにバプテスマをお授けになる」。

改革派教会が歴史的に聖書から告白してきたように、聖霊は「父と子（Filioque）」から送られます。では、昇天された栄光の主イエスが聖霊を「火」として送られる目的とは何でしょうか。

火の第一の特質とは<b>「焼き尽くし、不純物を精錬する」</b>ことです。金細工師が溶鉱炉の猛烈な火によって鉱石の中のドロス（不純物）を徹底的に焼き払い、純度100％の純金（24K）を精錬するように、聖霊の聖なる火は私たちの魂の深みに巣食う汚れた情欲、自己中心的な意志、肉の誇り、堕落した罪の性質を徹底的に焼き尽くされます。

同時に、聖書は聖霊の働きを「清めの水」としても描いています（エゼキエル36:25-27）。使徒パウロはテトスへの手紙第3章5節において、「私たちが尽くした義の行いによるのではなく、御自身の憐れみによって、<b>新生の洗いと聖霊による新しくすること</b>によって救ってくださった」と宣言しました。「新生（再生）」とは、人間の自由意志や功績が0.001％も介入しない、聖霊100％の主権的な恵みの御業です。

聖霊によって魂が清められた聖徒の内には、必然的に「罪と汚れを激しく憎み、神の聖潔を狂おしいほどに追い求める」という聖なる新しい性質が刻み込まれます。かつて暗黒の時代に福音が伝えられた際、真の信仰者が偶像の悪習を捨て去り、家庭と社会の不道徳を清め、清潔で聖なる生活へと立ち上がったように、霊的な清めは必ず生活全体の具体的な聖化として実を結びます。主イエスが聖霊を送られるのは、私たちを世の罪の泥沼から引き上げ、神の聖なる花嫁として清めるためなのです。清めなくして主を見ることはできません。聖霊の火が私たちの魂の内にある偶像を焼き払い、キリストの純粋な香りを放つ者へと造り変えてくださるのです。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：人間の知恵と肉の力を捨て去り、聖霊の権能によって神の国の働きを遂行するため（5節後半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  イエス様が弟子たちに「聖霊を待て」と命じられた三つ目の決定的な目的は、<b>「使徒たちと教会が、徹底して自分自身の肉の知恵や力ではなく、聖霊の超自然的な権能（デュナミス）によって主の奉仕と宣教を担うようにするため」</b>です。

イエス様ご自身も、ルカの福音書第4章にあるように、公生涯を始められるにあたって聖霊に満たされ、聖霊の油注ぎを受けて宣教の道を歩まれました。全能の神の御子であられる主イエスでさえ聖霊に依り頼まれたのであれば、まして罪深く無力な人間である私たちが、どうして聖霊なしに神の尊い御業を担うことができるでしょうか。

使徒たちもペンテコステの聖霊降臨を通して、天からの権能に満たされて初めて、ユダヤ人たちの脅迫を恐れず世界宣教の第一歩を踏み出すことができました。この霊的原則を最も鮮やかに体現したのが使徒パウロでした。パウロは当時の一流の学者であり、最高峰の哲学的教養と卓越した雄弁術を兼ね備えていました。しかし彼は、哲学の都アテネや大都市コリントに立った際にも、自らの知性や哲学的な議論、人間の弁舌の巧みさに頼ることは一切しませんでした。

パウロはコリントの信徒への手紙第一第2章1～5節において、血を吐くような思いでこう告白しています。<b>「兄弟たち、私があなたがたのところへ行ったとき、優れた言葉や知恵を用いて神の奥義を宣べ伝えることはしませんでした。なぜなら私は、あなたがたの間でイエス・キリスト、それも十字架につけられたキリストのほかには何も知るまいと決心していたからです……私の言葉や宣教は、知恵の説得力ある言葉によるのではなく、御霊と御力の現れによるものでした。それは、あなたがたの信仰が人間の知恵によらず、神の力によるものとなるためです。」</b>

教会の真の形成、罪人の回心、魂の救いは、人間の演出や心理操作、経営戦略によって成し遂げられるものではありません。ただ聖霊がその魂の心眼を開き、超自然的な信仰を呼び起こしてくださるゆえに成るのです。だからこそ、主イエスは人間的な計画で先走ることを厳しく禁じ、「聖霊を待て」と命じられたのです。教会が聖霊に頼ることをやめ、人間の知恵やプログラムに頼るとき、教会は霊的生命力を失い世俗化します。私たちは聖霊の力のみに依り頼まねばなりません。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に、[肉的な恐れや焦りを制し、祈りで主の約束を忍耐強く待ち望む訓練]：</strong> 生活の中で恐れや危機に直面したとき、自分の経験や計算で逃げ出したり先走ったりするのをやめましょう。エルサレムに留まり祈りつつ聖霊を待った使徒たちのように、み言葉の約束を握りしめ、主の時を忍耐強く待ち望む祈りの生活を確立してください。焦りは肉の働きであり、忍耐強い待望こそが霊の歩みです。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に、[聖霊の火と水による日々の聖化と徹底的な霊的清めの追求]：</strong> 単なる教理の知的な満足にとどまらず、聖霊の火によって心の内にある隠れた罪や利己的な誇りを焼き尽くしていただきましょう。毎日みことばの鏡の前に立ち、聖霊による心の清めと聖なる生活を熱心に祈り求めてください。罪を妥協せず、日ごとにキリストの聖なる姿へと造り変えられましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に、[人間の浅薄な知恵を捨て、御霊の力と権能に全幅の信頼を置く奉仕と伝道]：</strong> 家庭、職場、教会での奉仕において、自分の能力を誇る肉の働きを完全に退けましょう。パウロのように「御霊と御力の現れ」を求め、へりくだった祈りと従順をもって主の十字架の福音を力強く証しする神の器となってください。主が聖霊を通して働かれるとき、堅固な要塞も崩れ去ります。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、主イエス・キリストは、ご自身の愛する教会をこの世の恐怖や人間の無力の中に放置されませんでした。父が旧約の昔から約束され、御子が十字架と復活によって成し遂げられた完全な贖いの御業を土台として、最高の賜物である「聖霊」を豊かに注ぎ出してくださいます。

聖霊は、私たちに真理を悟らせる御霊であり、罪の腐敗性を焼き尽くし清める御霊であり、神の国のために力強く奉仕させる権能の御霊です。人間の肉的な思いや焦りを捨て去り、約束された聖霊の満たしを熱心に祈り求めつつ、現代の日本と世界の中で力強いキリストの生ける証人として歩み出す聖徒の皆様となりますよう、主イエス・キリストの尊き御名によって祝福いたします。
</p>
