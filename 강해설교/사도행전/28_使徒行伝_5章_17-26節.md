### 1. 序論：第2次迫害の勃発と神の絶対的勝利

使徒行伝第4章における第1次迫害に続き、本日の御言葉（使徒行伝 5:17-26）では、大祭司とサドカイ派が総力を結集した**「第2次組織的迫害」**が勃発します。

初代教会が罪を清められ、大いなる奇跡としるしによって男女の信徒の群れが爆発的に増加する様子を見て、宗教権力者たちは「嫉妬に燃え上がり」（17節）、使徒たち全員を捕らえて公の牢獄へと監禁しました。彼らは使徒たちの口を封じ、キリストの復活の教理とエルサレムに満ちる福音を力づくで根絶やしにしようとしたのです。

しかし、人間がどれほど強大な権力をもって神の御業を阻止しようとしても、神の御言葉を鎖で縛ることは決してできません。

その夜、神は御使い（天使）を遣わして厳重に施錠された牢の扉を開き、使徒たちを救い出されました。そして「どこかへ隠れていろ」ではなく、**「行って神殿に立ち、このいのちの言葉をすべて民に語りなさい」**（20節）と命じられたのです。翌朝、最高法院の議員たちが当惑する中で、使徒たちは再び神殿に堂々と立ち、恐れることなく民を教え続けました。

本日は、いかなる迫害の中にあってもご自身の愛する聖徒たちを守り、導き、勝利をもたらされる「神の超自然的な保護と主権の御業」を考察してまいりましょう。

### 2. 本論：聖徒を守られる神の三重の御業

```
【迫害の中で現れた神の主権的保護】
┌─────────────────────────────────────────────────────────┐
│ 1. 御使いによる迅速な救出（17-19節） ── 仕える霊の超自然的な働き │
│    ・ヘブル 1:14 / 施錠された扉を開き、夜の間に聖徒を解放する神 │
├─────────────────────────────────────────────────────────┤
│ 2. 「いのちの言葉」を語る使命（20-21節前半） ── 隠れず前進する勇気 │
│    ・マタイ 28:20, エペソ 1:11-14 / 救出の目的は神の栄光と宣教 │
├─────────────────────────────────────────────────────────┤
│ 3. 環境を動かして守られる主権（21節後半-26節） ── 敵の無力化 │
│    ・詩篇 27:1-3, 申命記 32:10 / 民衆の恐れを用い、手荒な扱いを防ぐ │
└─────────────────────────────────────────────────────────┘
```

#### 第1の要点：仕える霊を動員される「御使いによる迅速な超自然救出」（17-19節）

大祭司とサドカイ派によって公の牢に放り込まれた使徒たちを救うため、神が用いられた手段は**「主の御使い（天使）」**でした（19節）。

- **聖徒のために仕える霊（ヘブル人への手紙 1:14）：**
  「御使いは皆、仕える霊であって、救いを受け継ぐことになる人々に仕えるために遣わされたのではありませんか。」
  天の御座におられる父なる神と御子イエス・キリストは、危機の中にある聖徒を守るため、いつでも御使いたちを電光石火（Swift）のように遣わされます。
- **夜の間の即時介入（詩篇 30:5）：**
  「夕暮れには涙が宿っても、朝明けには喜びの叫びがある。」
  神は愛するしもべたちが牢の中で長く苦しむことを放置されませんでした。夜が明ける前に御使いを送り、番兵たちの目を塞ぎ、牢の扉を音もなく開いて使徒たちを連れ出されたのです（使徒行伝 12:7-10のペテロの脱出と同様）。
- **揺るがないシオンの土台（イザヤ書 28:16）：**
  「シオンに据えられた試みを経た礎石を信じる者は、慌てることがない。」
  神は私たちが直面する困難のただ中で、人間の策を超越した驚くべき方法をもって、一瞬にして救いをもたらしてくださいます。

---

#### 第2の要点：逃亡ではなく、神殿に立って「いのちの言葉」を語る使命（20-21節前半）

御使いが使徒たちを牢から救い出したとき、与えたメッセージに注目してください。
**「行って神殿に立ち、このいのちの言葉をすべて民に語りなさい。」（20節）**

御使いは「迫害の手が緩むまで遠くへ逃げて身を隠していなさい」とは言いませんでした。昨日捕らえられたまさにその場所、敵の総本山である神殿のど真ん中に立ち、堂々と福音を語り続けよと命じたのです。

1. **救出の真の目的（エペソ人への手紙 1:11-14）：**
   神が私たちを病や危機、苦難から救い出してくださるのは、単に私たちがこの世で安楽に暮らすためではありません。**「神の御国のために福音の使命を果たし、神の栄光を賛美するため」**です。
2. **「いのちの言葉」の宣布：**
   サドカイ派が恐れ嫌ったのは、死者をよみがえらせ、罪人に永遠の命を与えるキリストの「いのちの言葉」でした。使徒たちは夜明けとともに神殿に入り、一刻も早く渇いた民衆にこの命のパンを与え始めました。
3. **主の不変の同在の約束（マタイ 28:20）：**
   「見よ、わたしは世の終わりまで、いつもあなたがたと共にいる。」
   主が共にいてくださるゆえに、使徒たちにはもはや恐れもためらいもありませんでした。神の命令に対する即座の従順こそが、さらなる奇跡を呼び寄せる鍵です。

---

#### 第3の要点：敵の動きを封じ、環境をも動かして守られる「神の主権的配慮」（21節後半-26節）

翌朝、最高法廷で起きた光景は、神のユーモアと圧倒的な主権を見事に描き出しています。
議員たちが威厳を正して使徒たちを裁こうと牢へ役人を送ると、**「牢にはしっかり鍵がかかり、番兵も立っているのに、中は完全に空っぽ」**でした（23節）。彼らが当惑しているまさにその時、「牢に入れた者たちが神殿で民を教えている」という驚くべき知らせが飛び込んできました。

宮守頭と役人たちは再び使徒たちを連行しましたが、**「手荒なことはできなかった。民衆から石を投げつけられるのを恐れたからである」**（26節）。

- **状況を用いた神の防護幕（申命記 32:10, 創世記 12:3）：**
  神は荒野においてご自身の民を守り、「ご自身の瞳のように」護られます。神は民衆の支持と敬意という環境を用い、権力者たちが使徒たちに暴力や不当な処刑を行えないよう、彼らの手を完全に縛られたのです。
- **詩篇27篇1-3節の凱歌：**
  「主は私の光、私の救い。私はだれを恐れよう。主は私のいのちの砦。私はだれを怖がろう……たとい私に対して軍勢が陣を敷いても、私の心は恐れない。」
  神の御手のうちにある聖徒は、千人の敵が囲もうとも、主ご自身が安全な隠れ場となってくださいます。

### 3. 適用：迫害と困難の中で生きる3つの信仰的確信

私たちはこの使徒たちの劇的な救出劇から、日々の歩みにおいてどのような確信を持つべきでしょうか。

```
【神の絶対的保護に生きる3つの実践】
1. 御使いを遣わされる神への信頼 ── 孤立無援に見える時も、神の超自然的な助けを疑わない
2. 召命の場にとどまる勇気 ── 困難を理由に後退せず、与えられた場で「いのちの言葉」を語る
3. 環境を支配される主権への安息 ── 敵の脅威を恐れず、瞳のように守られる神の愛に憩う
```

#### ① どのような暗闇や行き詰まりの中にあっても、神の迅速な救出を信じる
人生の牢獄に閉じ込められ、前後左右が塞がれたように思える時でも、落胆してはなりません。
神は夜の間に御使いを遣わし、施錠された扉を開くことができる全能者です。祈りをもって主の救いを待ち望みましょう。

#### ② 苦難から救われた恵みを覚え、福音の使命に全力を尽くす
主があなたを生かし、助けてくださったのは、主の栄光のためです。
自分の安全や安楽ばかりを求めず、家庭や職場、地域社会の中で、キリストの「いのちの言葉」を愛と確信をもって証しする歩みを続けましょう。

#### ③ 主が周囲の環境を動かして守ってくださることを確信し、平安を保つ
人間関係の圧迫や世の不条理に脅かされるとき、詩篇27篇を告白してください。
主はすべての人の心と環境を支配しておられます。主の許しなしには一本の髪の毛さえ落ちません。主の主権に全幅の信頼を置き、恐れのない平安を保ちましょう。

### 4. 結論：神の計画を止めることができる力はこの世に存在しない

使徒行伝5章17節から26節は、**「悪魔のいかなる拘束も、神の福音の前進と聖徒の保護を妨げることはできない」**という輝かしい勝利を宣言しています。

大祭司とサドカイ派は使徒たちを牢に閉じ込めましたが、神は御使いを送って扉を開け、神殿のど真ん中でいのちの言葉を語らせられました。
この同じ全能の主が、今日も私たちと共にいてくださいます。御使いの助けと神の絶対的な主権を信じ、いかなる困難の中にあっても、確信と喜びをもって主の御言葉を宣べ伝えてまいりましょう。

### 5. 締めくくりの祈り

**全能にして歴史の絶対主権者であられる父なる神様。**
大祭司やサドカイ派の激しい嫉妬と迫害の中にあっても、主の御使いを遣わして牢の扉を開き、使徒たちを救い出して神殿でいのちの言葉を語らせられた、主の驚くべき御力を学ばせていただき、心より感謝申し上げます。

主よ、私たちが人生の様々な試練や行き詰まりに直面するとき、人の力や状況を見て恐れることなく、御使いたちを仕える霊として遣わし、瞳のように私たちを守ってくださる神の御手を仰ぎ見させてください。夜の涙を朝の喜びへと変えてくださる主の真実な約束に全幅の信頼を置かせてください。

また、私たちを苦難から救い出してくださる主の目的を覚え、身を隠して安楽を貪る者ではなく、置かれた生活の場で大胆に主イエスの「いのちの言葉」を証しする忠実なしもべとならせてください。敵の企てをことごとく無力化し、私たちを勝利へと導かれる主の御名を永遠に賛美いたします。

牢の扉を開き、私たちを真の自由と使命へと導かれる、主イエス・キリストの尊き御名によって、感謝と祈りを御前に捧げます。

**アーメン。**
