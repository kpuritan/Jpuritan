<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：主権者であられる聖霊の御業
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、ペテロの力強い福音の宣言の後、激論が交わされていたエルサレムの全会衆は水を打ったように静まり返りました。その静寂の中で、バルナバとパウロが立ち上がり、異邦人の間で神がどれほど驚くべきしるしと不思議を行われたかをありのままに語りました。<br><br>人間の激しい主張が静まり、聖霊の主権的な御業の前にすべての人が耳を傾けたのです。そして二人が語り終えると、エルサレム教会の指導者ヤコボが静かに立ち上がりました。聖霊こそが教会の真の支配者であり、混乱を静めて一致へと導かれる主権者です。本日は、人間の声を静め、神の御業に聞き入る霊的静けさと聖霊の主権を学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：主権者であられる聖霊の御業の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：人間の議論を沈黙させる聖霊の臨在と深い静寂（12節前半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  ペテロの証言の後、全会衆は静まり返りました。人間の知恵や議論が尽きるとき、聖霊の圧倒的な臨在が場を支配し、神の御声を聞くための静寂が生み出されます。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：異邦人の間で神が行われたしるしと不思議の生きた証言（12節後半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  バルナバとパウロは、神ご自身が異邦人伝道を承認された客観的なしるしを証ししました。教会の進むべき道は、人間の理論ではなく、生きて働かれる神の主権的御業によって裏付けられます。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：神の言葉に基づいて最終判断を導く指導者ヤコボの登壇（13節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  使徒たちの証言の後、ヤコボが穏やかに立ち上がりました。体験や奇跡の証言は、最終的に聖書の御言葉によって検証され、確証されなければなりません。聖霊は秩序と御言葉を通して教会を導かれます。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [自分の主張や感情的な議論を止め、主の御前で心を静めて耳を傾けること]：</strong> 教会の交わりや祈りの中で、人間の声を静めて聖霊の語りかけを待ち望みましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [日々の生活の中で神がなしてくださった具体的な御業を認め、証しすること]：</strong> 主が自分の周りでどのように働いておられるかを敏感に察知し、神の栄光を語り伝えましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [すべての体験や導きを、聖書の御言葉に照らして正しく吟味し従うこと]：</strong> 聖書の真理にしっかりと立ち、聖霊が与えてくださる知恵と一致を保ちましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、教会を真に導かれる方は主権者なる聖霊ご自身です。人間の議論を静めて主の御業に聞き入り、御言葉の真理に固く立って、聖霊が与えてくださる真の一致を守り続けてまいりましょう。
</p>
