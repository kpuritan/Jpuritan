  <div style="color: #334155; line-height: 1.85; font-size: 0.98em;">
<p style="margin-bottom: 8px; line-height: 1.85;"><strong style="color: #0A1C36; margin-right: 6px; font-feature-settings: 'tnum';">[16]</strong> あるとき、私たちが祈りの場所へ行く途中で、占いの霊につかれた女奴隷に出会った。彼女は占いをして、主人たちに多額の利益を得させていた。</p>
<p style="margin-bottom: 8px; line-height: 1.85;"><strong style="color: #0A1C36; margin-right: 6px; font-feature-settings: 'tnum';">[17]</strong> 彼女はパウロや私たちの後をついて来て、「この人たちは、いと高き神のしもべたちで、あなたがたに救いの道を宣べ伝えているのだ」と叫び続けた。</p>
<p style="margin-bottom: 8px; line-height: 1.85;"><strong style="color: #0A1C36; margin-right: 6px; font-feature-settings: 'tnum';">[18]</strong> 何日もこういうことをするので、パウロはひどく心を痛め、振り返ってその霊に言った。「イエス・キリストの御名によっておまえに命じる。この女から出て行け。」するとその霊は、ただちに出て行った。</p>
  </div>
</div>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：悪霊を追い出す権能と霊的見分け
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、ルディヤの救いによってピリピに教会が芽生え始めたとき、サタンの巧妙な霊的攻撃が始まりました。占いの悪霊につかれた一人の女奴隷が使徒たちの後をついて回り、「この人たちはいと高き神のしもべで、救いの道を宣べ伝えている」と叫び続けたのです。<br><br>言葉自体は正しいように見えましたが、その背後には福音と悪霊を混同させ、使徒たちの働きを妨害しようとするサタンの欺瞞がありました。パウロは深く心を痛め、振り返って「イエス・キリストの御名によって命じる。出て行け！」と命じ、悪霊を即座に追い出しました。本日は、サタンの欺瞞を見破る霊的識別力と、キリストの御名の圧倒的な解放の権能を学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：悪霊を追い出す権能と霊的見分けの救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：サタンの搾取と束縛の下にある人間の悲惨な現実（16節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  女奴隷は悪霊に操られ、主人たちからは金儲けの道具として搾取されていました。サタンの支配下にある人間は二重三重の束縛に苦しんでいます。福音はこの悲惨な束縛からの解放をもたらします。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：サタンの巧妙な欺瞞と使徒の霊的見分け（17-18節前半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  悪霊は正しい言葉を語ることで使徒たちに取り入り、真理を汚そうとしました。サタンは光の天使に変装します。パウロは肉的な名誉欲に惑わされることなく、悪霊の策略を霊的に見抜いて深く心を痛めました。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：イエス・キリストの御名の絶対的権能による悪霊の追放（18節後半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  パウロは自分の力ではなく「イエス・キリストの御名」によって命じました。暗闇の力はキリストの主権の御名にひれ伏すしかありません。悪霊は即座に出て行き、女奴隷に真の自由が訪れました。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [世の耳触りの良い言葉や偽りの霊的惑わしに騙されない霊的識別力を持つこと]：</strong> 外面的な正しさだけに惑わされず、聖霊の光によって背後にある霊の働きを見分けましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [サタンのあらゆる束縛や攻撃に対し、イエス・キリストの御名の権能によって立ち向かうこと]：</strong> 自分の弱さに怯えることなく、十字架で勝利されたキリストの尊き御名を呼び求めて祈りましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [罪や暗闇に苦しむ魂を憐れみ、キリストの福音による解放を届けること]：</strong> パウロのように魂の悲惨に心を痛め、キリストの愛をもって人々を真の自由へと導きましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、十字架でサタンの頭を打ち砕かれたイエス・キリストの御名には、すべての悪霊を追い出し魂を完全に解放する絶対的な権能があります。霊的見分けの知恵を持ち、キリストの御名の力によって世の暗闇に打ち勝ってまいりましょう。
</p>
