### 1. 序論：迫害の試練を突き抜けて輝く教会の栄光

サンヘドリン最高法廷による脅迫と禁止命令に対し、初代教会の聖徒たちが心を一つにして祈りを捧げたとき、大地は揺れ動き、一同は聖霊に満たされました。彼らは迫害という危機を、神の生きた臨在と奇跡を体験する「恵みの機会」へと変えたのです。

そして本日の御言葉（使徒行伝 4:32-37）は、その聖霊の注ぎの結果として、初代教会の内側に現れた**「驚くべき霊的共同体の姿」**を生き生きと描き出しています。

外部からの生命の危機と激しい弾圧の中にありながら、教会内部には世の常識では決して説明のつかない、計り知れない平安、喜び、愛の交わりが満ちあふれていました。それは、人間的な組織や地上のいかなる政府も決して模倣できない、**「神の恵みが力強く働いている真の教会だけの神聖な特徴」**でした。

本日は、初代教会に現れた「恵みに満ちた教会の三つの特徴」を考察し、現代の私たちが目指すべき真の教会と信仰生活の姿を学んでまいりましょう。

---

### 2. 本論：恵みに満ちた教会の三つの特徴

```
【恵みに満ちた教会の三つの霊的特徴】
┌─────────────────────────────────────────────────────────┐
│ 1. 御言葉の力強い宣布（33節前半） ── 復活の福音を大胆に証言 │
│    ・使徒 6:4, 11:26 / 祈りと御言葉への専念 / 堅固な教理の確立 │
├─────────────────────────────────────────────────────────┤
│ 2. 信徒にあふれる大いなる恵み（33節後半） ── 霊的解放と歓喜 │
│    ・使徒 13:48, イザヤ 12:3, 61:10 / 恐れからの解放と絶えざる賛美 │
├─────────────────────────────────────────────────────────┤
│ 3. 物質の聖別と自発的献身（32, 34-37節） ── マモンを克服した愛 │
│    ・Ⅱコリント 8:1-5（マケドニア教会） / レビ人バルナバの模範 │
└─────────────────────────────────────────────────────────┘
```

#### 第1の特徴：大きな権能をもって語られる「御言葉の力強い宣布」（33節前半）

恵みに満ちた教会の第1の特徴は、**「神の御言葉が力強く、純粋に宣べ伝えられていること」**です。
33節前半には、**「使徒たちは、主イエスの復活について、大いなる権能をもって証言し」**と記されています。

当時、最高法院は「イエスの復活を二度と語るな」と厳命していました。しかし、聖霊に満たされた使徒たちは、まさにその禁止された「キリストの復活の教理」を、以前にも増して大いなる力をもって語り続けたのです。

- **説教の純粋性の回復：**
  教会が世俗化し堕落するとき、講壇から聖書の深い解き明かしが消え、世の雑談、哲学、道徳論、政治的扇動が入り込みます。しかし、神の恵みが満ちる教会では、十字架の贖罪と復活のキリストという「純粋な福音の教理」が燃えるような情熱をもって語られます。
- **祈りと御言葉への専念（使徒行伝 6:3-4）：**
  使徒たちは教会の救済事務で忙殺されそうになったとき、直ちに七人の執事を立てて実務を委ね、自らは**「祈りと御言葉の奉仕に専念する」**体制を整えました。これこそが教会の霊的生命線の保持です。
- **御言葉による回心と成長（使徒行伝 11:24-26）：**
  アンティオキア教会において、バルナバとパウロが丸一年にわたり熱心に御言葉を教えた結果、弟子たちは初めて「キリスト者（クリスチャン）」と呼ばれるほど明確な変化を遂げました。教会を建て上げる根底には、常に豊かな聖書の教えがあります。

---

#### 第2の特徴：恐れを打ち破り、魂を満たす「大いなる恵みと歓喜」（33節後半）

第2の特徴は、信徒一同が**「非常に大きな恵み（メガ・カリス）を受けていた」**ことです。

当時の聖徒たちは、いつ捕らえられて投獄されるか分からない極限の脅威の中にありました。それにもかかわらず、聖書は彼らが「大いなる恵みを受けていた」と証言しています。彼らの心には、環境に左右されない天上の自由、確信、喜びが満ちあふれていたのです。

1. **御言葉を喜び賛美する生活（使徒行伝 13:48）：**
   「異邦人たちはこれを聞いて喜び、主の言葉を賛美し、永遠の命に定められている者は皆、信じた。」
   大きな恵みを受けた魂は、聖書をただ義務として読むのではなく、御言葉の一節一節を蜜のように甘く味わい、家庭や職場、日常のあらゆる場で心からの賛美を歌います。
2. **救いの泉から水を汲む歓喜（イザヤ書 12:2-3）：**
   「見よ、神は私の救い。私は信頼して恐れない。主なる神は私の力、私の歌、私の救いとなられた。あなたがたは喜びをもって、救いの泉から水を汲む。」
3. **救いの衣を着せられた喜び（イザヤ書 61:10）：**
   「私は主によって大いに喜び、私の魂はわが神によって歓喜する。主が私に救いの衣を着せ、義の上着をまとわせてくださったからである。花婿が冠をいただき、花嫁が装飾品で身を飾るように。」
   結婚式の花婿と花嫁が喜びを隠せないように、キリストによって罪赦され義とされた聖徒の心には、世が奪うことのできない聖霊の喜びが溢れ返るのです。

---

#### 第3の特徴：マモンの束縛を断ち切る「物質の聖別と自発的な愛の分かち合い」（32, 34-37節）

第3の特徴は、恵みの実りが**「信徒たちの経済生活と物質観の根本的変革」**として具体的に現れたことです。

**「信じた人々の群れは、心を一つにし、思いを一つにして、だれ一人自分の財産を自分のものと主張せず、すべての物を共有していた……彼らの中には、乏しい者が一人もいなかった。」（32, 34節）**

主イエスは「神と富（マモン）とに兼ね仕えることはできない」（マタイ 6:24）と教えられました。人間にとって最も自己中心性が現れやすい「お金と財産」の領域において、神の恵みによる奇跡が起こったのです。

- **自発的な愛の献身（共産主義との決定的一線）：**
  これは国家権力による強制的な財産没収（共産主義）ではなく、**「キリストの愛に圧倒された聖徒たちが、自発的に困窮する兄弟姉妹のために私財を捧げた愛の実践」**でした。
- **マケドニア教会の模範（Ⅱコリント 8:1-5, 9:11-13）：**
  エルサレム教会の飢饉の際、マケドニアの信徒たちは「極度の貧しさの中にあっても、あふれる喜びに満ち、力以上に自発的に」豊かな献金を捧げました。彼らはまず自分自身を主に献げていたからこそ、惜しみなく施すことができたのです。
- **レビ人バルナバの生きた証し（36-37節）：**
  キプロス生まれのレビ人ヨセフ（バルナバ＝「慰めの子」）は、自分の畑を売り、全代金を使徒たちの足もとに置きました。律法の形式的な義務からではなく、福音の恵みに心打たれ、純粋な愛から捧げたのです。

真に救いの恵みを受けた人は、物質を自分の所有物として握りしめるのをやめ、「神から委託された良き清教徒的管理者（スチュワード）」として、神の栄光と教会の必要のために豊かに用いるようになります。

### 3. 適用：現代の教会と聖徒が回復すべき3つの恵みの姿

私たちはこの初代教会の美しい姿から、日々の信仰生活において何を点検し、実践すべきでしょうか。

```
【恵みに満ちた信仰生活の3つの実践】
1. 御言葉の学びと教理の確立 ── 講壇の説教を熱心に聞き、聖書を深く黙想する
2. 救いの喜びと賛美の回復 ── 試練の中でも救いの恵みを思い起こし、日々に賛美を満たす
3. 物質の聖別と気前の良い分かち合い ── 富への執着を捨て、神の国と隣人のために豊かに献げる
```

#### ① 聖書の真理と教理の学びに全力を注ぐ
教会と家庭の中心に御言葉を据えましょう。世の流行やエンターテインメントに流されず、純粋なキリストの福音と健全な教理を熱心に学び、教え合う共同体を築きましょう。

#### ② 日常生活の中で「大いなる恵み」の喜びを賛美する
主の日だけでなく、月曜日から土曜日までの日々の生活の中で、救いの泉から水を汲みましょう。
どんな苦難やストレスがあっても、キリストが着せてくださった「義の衣」を覚え、祈りと賛美をもって感謝の生活を送りましょう。

#### ③ 物質の主人である神を認め、愛をもって仕え献げる
私たちが持つ時間、健康、財産はすべて主から委ねられたものです。
利己的な執着を捨て、教会の福音伝道のため、また困難の中にある兄弟姉妹のために、バルナバのように気前よく自発的に分かち合う清らかな手を保ちましょう。

### 4. 結論：世を圧倒する真の教会の生命力

使徒行伝4章32節から37節に記された初代教会の姿は、**「聖霊の恵みが満ちるとき、教会はいかなる迫害をも超えて、この世が到底太刀打ちできない神聖な光を放つ」**ことを力強く証言しています。

- 力強い御言葉の宣布
- 恐れを吹き飛ばす大いなる歓喜
- 貧しい者を一人も残さない自発的な愛の献身

この三つの恵みの特徴が私たちの教会と日々の生活の中に豊かに現れ、暗い現代社会にあって主イエス・キリストの生ける栄光を証ししてまいりましょう。

### 5. 締めくくりの祈り

**恵みと愛の源であられる父なる神様。**
初代教会の聖徒たちが、厳しい迫害の嵐の中にあっても、御言葉の力強い宣布に養われ、大いなる恵みと喜びに満たされ、物質の執着を捨てて互いに愛し合い仕え合った崇高な姿を学ばせていただき、心より感謝申し上げます。

主よ、私たちの教会が世俗化の波に呑まれることなく、常に十字架と復活の純粋な御言葉が力強く語られ、聖徒たちが大きな救いの恵みに満たされる教会とならせてください。私たちの唇から日々に感謝と賛美が絶えることなく、救いの泉から喜びの水を汲み続ける者とならせてください。

また、私たちがマモンの偶像を打ち砕き、神から委ねられた財産や賜物を、主の御国の前進と困窮する兄弟姉妹のために喜んで献げる、豊かな愛の器として用いてください。

教会を建て上げ、御自身の命をもって私たちを買い取ってくださった、主イエス・キリストの尊き御名によって感謝し、お祈りいたします。

**アーメン。**
