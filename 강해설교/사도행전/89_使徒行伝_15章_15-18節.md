<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：再び建て直されるダビデの幕屋
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、ヤコボはペテロの証言を旧約聖書アモス書の預言に照らし合わせました。「この後、わたしは帰って来て、倒れたダビデの幕屋を建て直す。それは、すべての異邦人が主を求めるようになるためである。」<br><br>ダビデの倒れた幕屋とは、崩壊した地上の王国ではなく、ダビデの子孫として来られたイエス・キリストの十字架と復活によって再興される「霊的神の国」です。そしてその目的は、すべての異邦人が主を求めるようになることでした。本日は、聖書の預言の壮大な成就と、キリストによって永遠に再興された神の国を学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：再び建て直されるダビデの幕屋の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：聖書の御言葉によって体験を検証し確証する使徒的原則（15節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  ヤコボは個人的な体験や奇跡だけで結論を下すのではなく、旧約預言者たちの御言葉と一致しているかを確かめました。聖書こそが教会の教理と実践の最終的かつ絶対的な基準です。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：キリストの復活による「ダビデの幕屋」の完全な再興（16節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  神はキリストの救済の御業によって、罪によって崩壊していたダビデの王国を霊的に再建されました。キリストの教会こそ、再興されたダビデの幕屋の実質であり、永遠に揺るがない神の国です。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：万民が主を求めるようになるという神の永遠の救済計画（17-18節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  異邦人の救いは突然の思いつきではなく、「昔から知らせておられた」神の永遠の御旨でした。主の御名で呼ばれるすべての民族が主を慕い求めるようになることこそ、救済史の栄光あるゴールです。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [教会のすべての決定や信仰の体験を、聖書の御言葉に照らして正しく吟味すること]：</strong> 人間の感情や世の流行に流されず、聖書の確かな真理の上に信仰を堅く築きましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [キリストにあって再建された神の国の民として、誇りと感謝をもって生きること]：</strong> 倒れることのない永遠の御国の世継ぎとされた喜びを胸に、主の統治に従順に従いましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [すべての民族が主を求めるようになる世界宣教のビジョンを共有し、祈り励むこと]：</strong> 太古からの神の救済計画の成就にあずかり、異邦人に福音を届ける働きを熱心に支えましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、神は約束どおりダビデの幕屋をキリストにおいて再建し、私たちをその栄光ある御国へと招き入れてくださいました。聖書の真理に固く立ち、万民を主へと導く宣教の器として力強く前進してまいりましょう。
</p>
