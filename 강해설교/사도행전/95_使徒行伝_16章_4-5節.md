<p style="margin-bottom: 8px; line-height: 1.85;"><strong style="color: #0A1C36; margin-right: 6px; font-feature-settings: 'tnum';">[5]</strong> こうして諸教会は信仰を強められ、日ごとに人数を増していった。</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：教会に加えられる祝福
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、パウロとシラス、そしてテモテの宣教チームは町々を巡り、エルサレム会議で決議された福音の自由の規定を諸教会に伝えました。律法のくびきから解放された知らせは、信徒たちに真の平安をもたらしました。<br><br>そして聖書は美しく証言します。「こうして諸教会は信仰を強められ、日ごとに人数を増していった。」 正しい教理の上に立ち、愛と一致を守る教会には、霊的な深化と量的な成長という神の豊かな祝福が必ず伴います。本日は、教会に加えられる神の祝福の秘訣を学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：教会に加えられる祝福の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：健全な使徒的教理と公的決議の忠実な伝達（4節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  使徒たちは個人的な意見ではなく、教会全体の一致による決定を忠実に伝えました。健全な教理と秩序が確立されている教会こそ、惑わしの多い世にあって信徒を安全に守る砦となります。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：信仰の内的な強化と霊的基盤の確立（5節前半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  「諸教会は信仰を強められた。」 人数の増加の前に、まず信徒一人ひとりの信仰が御言葉によって固く確立されました。内的な質の深化なくして真の教会の前進はありません。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：主が与えてくださる日ごとの人数増加の祝福（5節後半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  信仰が強められた教会には、神が日ごとに新しい信徒を加えてくださいました。教会の成長は人間の技巧によるものではなく、御言葉と聖霊に満たされた健全な共同体に神が注がれる自然な結実です。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [聖書の健全な教理に堅く立ち、教会の秩序と指導を大切にすること]：</strong> 信仰の基準を曖昧にせず、改革派の確かな真理に根ざして歩みましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [外的な数よりも、まず自分自身の信仰が内側から強められることを求めること]：</strong> 日々の御言葉と祈りを通して主との交わりを深め、揺るぎない信仰の土台を築きましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [教会に新しい魂が救われ加えられるよう、熱心に祈り福音を証しすること]：</strong> 温かく愛に満ちた共同体を築き、主が救われる人々を日ごとに加えてくださる恵みを期待しましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、真理の福音に堅く立ち、互いに愛の一致を守る教会を、神は必ず強め、日ごとに成長させてくださいます。内なる信仰を強められ、救いの実りを豊かに刈り取る祝福の教会となってまいりましょう。
</p>
