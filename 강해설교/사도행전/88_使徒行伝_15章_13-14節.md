<p style="margin-bottom: 8px; line-height: 1.85;"><strong style="color: #0A1C36; margin-right: 6px; font-feature-settings: 'tnum';">[14]</strong> シモンが説明したように、神は初めに、異邦人の中からご自分の御名のために一つの民を選び取ろうとして、御心を留められました。</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：神の救いの方法と御名の民
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、エルサレム会議において、主の兄弟であり教会の柱であったヤコボが最終的な結論を導くために口を開きました。ヤコボは使徒ペテロの証言を要約し、「神は初めに、異邦人の中からご自分の御名のために一つの民を選び取ろうとされた」と宣言しました。<br><br>救いとは、人間が神を探し求めることではなく、神ご自身が暗闇の世の中からご自身の栄光のために民を選び出される主権的な御業です。本日は、救済史を貫く神の救いの方法と、神の御名のために買い取られた聖徒の尊い身分を学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：神の救いの方法と御名の民の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：神の先立つ顧みと主権的訪問（13-14節前半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  ヤコボは「神が御心を留められた（エペスケプサト＝訪ねられた）」と語りました。異邦人が救われたのは、神が自ら彼らを顧み、恵みをもって訪れてくださったからです。救いの主導権は100%神にあります。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：異邦人の中から「ご自身の御名のための民」を選び取る救いの目的（14節中盤）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  神の救いの目的は、単に人間を地獄から救うだけでなく、「ご自身の御名（栄光）のための民」を形成することです。私たちは主の栄光と讃美を世に現すために選ばれた特別な宝です。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：民族的枠組みを打破し、新しい契約の民を創造される神の知恵（14節後半）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  「民（ラオス）」という言葉は、かつてイスラエルのみに用いられていた尊称でした。神は今や異邦人をもご自身の契約の「民」として受け入れられました。キリストにあって新しい神のイスラエルが誕生したのです。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [私が救われたのは神が一方的な愛をもって訪ねてくださった恵みであることを覚えること]：</strong> 自分の功績を一切誇らず、無価値な自分を選び出してくださった神の愛に感謝しましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [「主の御名のための民」として、神の栄光を生活の中で現すこと]：</strong> 日々の思いや言葉、行動を通して、主の聖なる御名が崇められる生き方を志しましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [教会が民族や境遇を越えた神の新しい家族であることを喜び、一致を守ること]：</strong> すべての人に開かれた神の救いの広大さを讃美し、互いを神の尊き民として愛し敬いましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、私たちは神がご自身の御名のために選び取ってくださった尊い民です。この偉大なる選びの恵みに感謝し、神の栄光と賛美を全世界に響かせる真の礼拝者として歩んでまいりましょう。
</p>
