<p style="margin-bottom: 8px; line-height: 1.85;"><strong style="color: #0A1C36; margin-right: 6px; font-feature-settings: 'tnum';">[4]</strong> エルサレムに到着すると、彼らは教会と使徒たちと長老たちに迎えられ、神が自分たちとともに行われたすべてのことを報告した。</p>
<p style="margin-bottom: 8px; line-height: 1.85;"><strong style="color: #0A1C36; margin-right: 6px; font-feature-settings: 'tnum';">[5]</strong> ところが、信者となったパリサイ派の人々が立ち上がり、「異邦人にも割礼を受けさせ、モーセの律法を守るように命じるべきだ」と言った。</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：真理と恵みの中にある者たち
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、エルサレムへと向かうパウロとバルナバは、道中のフェニキアやサマリアの諸教会に立ち寄り、異邦人たちがどのように主のもとに立ち返ったかを詳しく証ししました。兄弟たちはこれを聞いて大いなる喜びに包まれました。<br><br>エルサレムに到着した一行は温かく迎えられましたが、教会内のパリサイ派出身の信徒たちが立ち上がり、「異邦人にも割礼を受けさせ、律法を守らせるべきだ」と再び要求しました。真理と恵みを喜ぶ魂と、古い律法の枠にとらわれる者たちとの対比が鮮明に現れています。本日は、神の恵みの広大さを喜ぶ霊的解放を学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：真理と恵みの中にある者たちの救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：異邦人の救いの報告と聖徒たちに満ちあふれる大きな喜び（3節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  フェニキアやサマリアの兄弟たちは、異邦人がキリストにあって救われた知らせを聞いて純粋に大喜びしました。真理と恵みの内にある魂は、神の家族が増え広がることを自分のことのように喜ぶ広い心を持っています。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：神が共になされた御業の報告とエルサレム教会の歓迎（4節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  パウロたちはエルサレムの使徒や長老たちの前でも、神が共に行われた偉大な救済の御業をありのままに報告しました。神の国の前進の現実は、どのような人間的な偏見をも圧倒する証拠となります。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：古き宗教的枠組みに固執するパリサイ派信徒の限界（5節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  キリストを信じながらも、かつてのパリサイ派の律法主義的思考から抜け出せない人々がいました。救われた後も、過去の宗教的習慣や自分のこだわりを他人に押し付けようとする肉の傾向を私たちは警戒しなければなりません。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [他者の救いや教会の恵みのニュースを心から喜び、神を讃美すること]：</strong> 偏狭な心を捨て、主が世界中で行っておられる救いの御業を共に喜び祝いましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [救われた後も残る自分の古い宗教的枠組みや偏見を御言葉によって打ち砕くこと]：</strong> 聖書の真理に基づかない人間的な規則や条件を他人に押し付ける過ちを犯さないよう注意しましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [神が共になされた恵みの御業を明確に分かち合い、共同体の信仰を強めること]：</strong> 自分の生活の中で神が働いてくださった生きた証しを語り、周囲に恵みの波を広げましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛하는 兄弟姉妹の皆様、真理と恵みの中にある者は、神の救いの広大さを喜んで受け入れます。古い律法の枠を打ち破り、キリストの完全な恵みを共に喜び賛美する広やかな心をもって歩んでまいりましょう。
</p>
