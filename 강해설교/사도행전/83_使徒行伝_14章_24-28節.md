<p style="margin-bottom: 8px; line-height: 1.85;"><strong style="color: #0A1C36; margin-right: 6px; font-feature-settings: 'tnum';">[28]</strong> そして、二人は弟子たちとともに長い期間を過ごした。</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  1. 序論：宣教の報告と神の御業の讃美
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する聖徒の皆様、パウロとバルナバは数々の死線を越え、第1回宣教旅行の全行程を完遂して、送り出し母教会であるシリアのアンテオケへと帰還しました。彼らは教会全体を招集し、宣教の偉大な報告会を開きました。<br><br>彼らが語ったのは、自分たちの苦労や武勇伝ではなく、「神がともに行われたすべてのこと」であり、「神が異邦人に信仰の門を開いてくださったこと」でした。宣教の主役は常に神ご自身です。本日は、使命を成し遂げた者たちの謙遜な報告と、世界に信仰の門を開かれた神への大いなる賛美を学んでまいりましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  2. 本論：宣教の報告と神の御業の讃美の救済史的展開
</h3>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第1の要点：神の恵みに委ねられた使命の完遂と帰還（24-26節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  使徒たちは出発時に「神の恵みに委ねられた」とおり、神の守りの中でその尊い任務を完全に成し遂げました。人間の力ではなく、神の先立つ恵みこそがすべての働きを支え完成させます。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第2の要点：神が共に行われた御業と「信仰の門」の開放の報告（27節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  パウロたちは自分たちの手柄を語るのではなく、「神が共になされたこと」「神が異邦人に信仰の門を開かれたこと」を証ししました。宣教の扉を開かれるのは神の主権であり、すべての栄光は神のみに帰されるべきです。
</p>

<h4 style="font-size: 1.08em; font-weight: 700; margin-top: 22px; margin-bottom: 10px; color: #1e293b; background: #f8fafc; padding: 8px 14px; border-left: 4px solid #3b82f6; border-radius: 0 4px 4px 0;">
  第3の要点：弟子たちとの深い交わりと次なる前進のための安息（28節）
</h4>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  宣教旅行を終えた使徒たちは、アンテオケの聖徒たちと長い時間を共に過ごし、互いに霊的な交わりと安息を深めました。教会の交わりは、次の宣教の働きへと向かうための豊かな充電の場です。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  3. 適用：生活の中で実践する信仰
</h3>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第一に, [自分に託された日々の使命を、神の恵みに信頼して最後まで忠実に完遂すること]：</strong> 主が委ねてくださった場所で、神の助けにより頼んでベストを尽くしましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第二に, [あらゆる働きや実りを自分の手柄とせず、神がなされた御業として証しすること]：</strong> すべての成功と恵みを神の主権によるものと認め、へりくだって神をほめたたえましょう。
</p>
<p style="margin-bottom: 10px; line-height: 1.85; padding-left: 14px; position: relative;">
  <span style="color: #3b82f6; font-weight: bold; margin-right: 6px;">&bull;</span><strong>第三に, [教会の交わりを大切にし、互いに主の恵みを分かち合って励まし合うこと]：</strong> 主が生活の中で開いてくださった信仰の門を証しし合い、共に主の御名を讃美しましょう。
</p>

<h3 style="font-size: 1.22em; font-weight: 700; margin-top: 32px; margin-bottom: 14px; color: #0A1C36; border-bottom: 2px solid #e2e8f0; padding-bottom: 8px; display: flex; align-items: center; gap: 8px;">
  結論：恵みと決断
</h3>
<p style="margin-bottom: 12px; line-height: 1.85; color: #1e293b; text-align: justify;">
  愛する兄弟姉妹の皆様、神は今日も世界中に「信仰の門」を開いておられます。すべての働きを神の恵みに委ね、神が共になしてくださる驚くべき御業を喜び証しする忠実な僕として歩んでまいりましょう。
</p>
